# 🍴 Midi-Mealy

> ⚠️ Projet en cours de développement (WIP), à but d'apprentissage personnel.

Application de découverte de restaurants pour équipes de bureau. Les utilisateurs rejoignent un bureau (office), voient les restaurants à proximité via OpenStreetMap, et laissent des avis.

## Stack technique

- **TanStack Start** + **TanStack Router** + **TanStack Query** — framework SSR full-stack
- **React 19** + **TypeScript**
- **Supabase** — auth + base de données PostgreSQL
- **Tailwind CSS** + **Shadcn/ui**
- **Leaflet / React-Leaflet** — cartes interactives
- **Nominatim** (geocoding) & **Overpass API** (restaurants OSM)
